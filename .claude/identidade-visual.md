# Identidade Visual Desiberne — Referência Central

Este arquivo é a fonte única de verdade sobre a identidade visual da Desiberne.
Referenciado por DESIGNER e SENTINELA. Atualizar aqui quando a marca evoluir.

---

## Princípio central

**Identidade constante ≠ logo constante.**

A marca deve ser reconhecível mesmo quando o logo não aparece.
O reconhecimento vem da linguagem — tipografia, hierarquia, composição, paleta, ritmo, escolha de imagens.
O logo é uma assinatura. Não é decoração. Não é preenchimento.

---

## DNA Visual

A Desiberne deve parecer:
- Sofisticada
- Tecnológica
- Humana
- Inteligente
- Contemporânea
- Editorial
- Estratégica
- Comercial sem aparência de propaganda barata

A Desiberne NÃO deve parecer:
- Cyberpunk
- Startup genérica de IA
- Propaganda de ferramenta de IA
- Apresentação corporativa antiga
- Template de Canva
- Banco de imagens genérico
- Arte criada por IA seguindo template

**A tecnologia é parte da identidade. Não precisa aparecer visualmente em todas as peças.**

## Paleta oficial

| Nome | Hex | Uso |
|------|-----|-----|
| Preto Desiberne | `#01010A` | Fundo principal, textos em fundos claros |
| Azul elétrico | `#009FF7` | Acento primário, destaques, CTAs |
| Azul profundo | `#3245A9` | Acento secundário, gradientes discretos |
| Roxo | `#9945F4` | Acento terciário, uso pontual |
| Magenta | `#D04BEA` | Acento de alto impacto — usar com parcimônia |
| Branco | `#FFFFFF` | Texto em fundos escuros, fundos claros |
| Cinza claro | `#E6E8EF` | Fundos secundários, separadores |

### Paleta como sistema de acentos

Não usar todas as cores em toda peça.
Cada peça deve ter uma cor dominante e no máximo dois acentos.

Combinações válidas por tipo de peça:

| Tipo | Combinação |
|------|-----------|
| Institucional / comercial | `#01010A` + `#FFFFFF` + acento `#009FF7` |
| Editorial forte | `#FFFFFF` + `#01010A` (só tipografia) |
| Destaque tecnológico | `#01010A` + `#009FF7` + `#3245A9` |
| Conteúdo premium | `#01010A` + `#9945F4` discreto |
| Foto editorial | Fotografia + `#01010A` overlay + `#FFFFFF` texto |
| Leve / educativo | `#FFFFFF` + `#01010A` + acento único |

**Proibido: gradiente azul-roxo-magenta como fundo principal de toda peça.**
Gradientes são recursos — não identidade base.

## Aplicações do logo

### A — Logo horizontal

Uso principal da marca.

Usar em:
- Capa institucional
- Apresentações
- Propostas
- Peças institucionais
- Encerramentos de carrossel comercial
- Materiais de venda
- Assinaturas de marca

### B — Símbolo circular / D

Assinatura secundária — menor, mais discreta.

Usar em:
- Canto de peças editoriais
- Marca d'água discreta
- Avatar de perfil
- Assinatura editorial de carrossel
- Peças onde o logo horizontal ocuparia espaço excessivo
- Conteúdo de autoridade com presença de marca reduzida

### C — Logo para fundo escuro

Versão com contraste para fundos `#01010A` e navy.
Usar sempre que o fundo for escuro e o logo for necessário.

## Regra de uso do logo por contexto

| Contexto | Aplicação | Observação |
|----------|-----------|------------|
| Capa de carrossel | Pode — se contribuir para composição | Não obrigatório |
| Slides internos | Normalmente NÃO usar | Narrativa deve dominar |
| Slide de encerramento | Recomendado | Logo horizontal ou símbolo |
| CTA final | Recomendado | Assinatura da oferta |
| Conteúdo editorial | Símbolo discreto | Priorizar conteúdo |
| Conteúdo educativo | Opcional | Legibilidade em primeiro lugar |
| Conteúdo de autoridade | Símbolo discreto | Não interromper o argumento |
| Conteúdo comercial | Mais evidente | Contexto de venda justifica |
| Manifesto | Parcimônia | Deixar a ideia dominar |
| Carrossel narrativo | Somente encerramento | Narrativa é protagonista |

**Para carrosseis de 7–10 páginas: logo em no máximo 2 slides (capa opcional + encerramento).**

---

## Regras de logo — inegociáveis

- NUNCA deformar, redesenhar, recriar ou reinterpretar o logo
- NUNCA pedir para IA generativa "criar um logo semelhante"
- NUNCA usar como elemento decorativo de preenchimento
- NUNCA aplicar em todas as páginas de um carrossel sem justificativa
- SEMPRE usar a versão correta para o fundo (claro ou escuro)
- Quando usar ferramenta de IA para gerar imagem: o logo é asset fornecido na composição final — não elemento a ser inventado pela IA

## Fotografia

### Priorizar

- Fotografia editorial — composição intencional
- Pessoas reais com expressões naturais
- Ambientes plausíveis e relacionados ao assunto
- Diversidade real
- Iluminação fotográfica (não estúdio genérico)
- Contexto de negócio real: escritório real, atendimento real, produto real

### Evitar absolutamente

- Empresário sorrindo para câmera com fundo branco
- Aperto de mãos (stock clássico)
- Reunião genérica em volta de laptop
- Pessoa apontando para gráfico ascendente
- Robôs e hologramas
- Cérebro digital
- Humano olhando para código
- Escritório futurista genérico
- Pessoas artificialmente perfeitas (geradas por IA)
- Qualquer imagem que pareça banco de stock de 2015

**A imagem deve ajudar a contar a história do conteúdo — não decorar a peça.**

## Tipografia

Diretrizes gerais (adaptar conforme ferramenta disponível):

| Uso | Estilo |
|-----|--------|
| Headline principal | Serif bold ou sans-serif bold com peso máximo |
| Corpo de texto | Sans-serif regular, legível em tamanho pequeno |
| Dado / número em destaque | Fonte de display — peso máximo |
| Citação / estilo editorial | Serif itálico |
| CTA / botão | Sans-serif bold, uppercase ou sentence case |

Tipografia forte pode ser o único elemento visual de um slide — sem foto, sem gradiente.

## Variação visual obrigatória

A identidade é fixa. A execução varia.

Formatos possíveis (rotar entre peças de uma mesma série):

| Formato | Quando usar |
|---------|-------------|
| Fotografia editorial + headline | Conteúdo de impacto, provocação |
| Tipografia pura | Argumento forte que não precisa de imagem |
| Dado destacado | Estatística, número, resultado |
| Comparação visual | Antes/depois, errado/certo |
| Storytelling slide a slide | Narrativa com progressão |
| Manifesto | Posicionamento e valores |
| Estilo editorial | Conteúdo de autoridade |
| Estilo conversa | Tom direto, íntimo |
| Gráfico simples | Dados com hierarquia visual clara |
| Conteúdo comercial | CTA evidente, proposta de valor |

Peças consecutivas no calendário **não devem usar o mesmo formato visual**.
